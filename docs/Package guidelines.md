Objective: Design and Develop a web-based database application using client-server architecture      

*  Two students per team.  
* Identify all data requirements of your database application   
*  Develop an ER diagram using  **ER Studio/  ERD Plus**  
* The E-R diagrams should indicate cardinality on all relationships, any derived attributes, and weak entities, and the DDL must appropriately implement them. 8 to 10 entity sets are expected.  
* Relational tables are normalized to at least a third normal form, With good E-R design this should naturally occur.  
* Build the database with appropriate data constraints and All foreign key relationships should be implemented with appropriate UPDATE and DELETE clauses.   
* Populate the database with rich data  and ensure that there are enough entries to demonstrate functionalities.   
* The user front end (GUI- Graphical user interfaces)  
* The project must be able to create, read, update and delete data from the chosen database.  
* The executed operations should be driven from user input, implemented using   stored procedures and functions   
*  The user interface for the project may be a  web page or a GUI based project. The user interface provides access to the database and determines the operations that are executed on the data.  
* Implement Triggers to enforce business rules (2 constraints)
